Pick two

Decisions

My pick: C for the list, B for the guild page. Rows read best and show all ten without scrolling, and two columns fit a whole guild on one screen. If you want the atmosphere, D is C with a painting on top — you can add it later without redrawing anything.
Is one hall painting enough, or does each guild want its own? One painting for all ten reads a bit generic. Ten paintings is about 250KB more and a much better screen. The emblems already give each guild an identity, so this is a nice-to-have rather than a must.
Are the emblems good enough to ship? They are generated, so they are close but not perfect — a couple read better than others at 30px. If A or C wins, the small size hides most of it. If B wins, the art is on screen at 104px and the weaker ones want redrawing.
File size. The game file is already 5.96 MB and the desktop updater aborts a download at six seconds, which needs about 8.4 Mbps. {{TOTALKB}}KB of guild art is not what breaks that, but it is worth knowing the budget is already thin.
Nothing here is built yet. Every panel is drawn in this page with the game's own colours and fonts at the real panel width. The art was generated locally on Z-Image-Turbo — see _guildsimple/genart.js.
